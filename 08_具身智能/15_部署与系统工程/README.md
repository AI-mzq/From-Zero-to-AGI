# 15_部署与系统工程

> 把感知、模型、规划和控制组合成满足实时性、稳定性与资源约束的机器人系统。

## 本章定位

具身模型只有进入闭环系统才会暴露真实问题。本章关注端侧推理、云边协同、模块接口、时间同步、日志回放、故障处理和安全降级等工程能力。

## 核心问题

- 感知、推理、规划和控制的延迟预算如何分配？
- 大模型推理如何适配机器人端侧算力与功耗？
- 云端与本地分别适合承载哪些能力？
- ROS、硬件接口和模型服务如何稳定集成？
- 如何通过日志、回放、监控和故障注入定位问题？
- 模型失效时系统如何停止、降级或交还控制权？

## 系统链路

```text
传感器 → 实时感知 → 模型与规划服务 → 控制接口
→ 安全检查 → 执行 → 日志与监控 → 回放和改进
```

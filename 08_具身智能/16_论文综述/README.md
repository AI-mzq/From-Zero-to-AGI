# 16_论文综述

> 按知识主线阅读具身智能论文，理解代表工作解决了什么问题，以及证据能支持什么结论。

## 本章定位

本章连接基础概念、代表论文和技术演进，按感知、机器人学习、VLA、世界模型、数据、泛化与评测等问题域组织阅读，而不是形成无限增长的论文列表。

## 核心问题

- 一篇论文改变了系统链路中的哪一环？
- 能力提升来自架构、数据、训练策略还是评测设置？
- 实验是否覆盖新任务、新场景和真实机器人？
- 论文结论能否跨机器人本体和数据分布成立？
- 哪些工作具有奠基意义，哪些适合作为当前代表案例？

## 论文阅读框架

```text
研究问题 → 任务与本体 → 数据来源 → 模型与动作表示
→ 训练方法 → 评测设置 → 结果证据 → 局限与可迁移结论
```

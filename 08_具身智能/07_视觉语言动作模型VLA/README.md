# 07_视觉语言动作模型 VLA

> 理解视觉、语言、机器人状态和动作如何进入同一个基础模型。

## 本章定位

VLA 将视觉语言模型的理解能力延伸到机器人动作生成。本章围绕输入表示、动作空间、模型结构、训练流程和闭环推理，解释 VLA 与 VLM、传统策略模型之间的关键差异。

## 核心问题

- VLM 为什么不能直接成为可靠的机器人策略？
- 图像、语言、本体状态和动作如何联合表示？
- 动作 Token、动作专家和分层策略分别如何工作？
- VLA 的预训练、后训练和推理流程是什么？
- 数据效率、实时性、长时程规划和安全为什么仍是瓶颈？

## 基本结构

```text
视觉观测 + 语言指令 + 本体状态
→ 多模态编码与融合 → 策略推理
→ 动作表示或动作专家 → 机器人执行
```

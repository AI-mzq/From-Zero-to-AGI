# 11_泛化与跨本体迁移

> 让机器人策略从训练任务走向新环境、新对象、新指令和不同机器人本体。

## 本章定位

本章关注策略在新任务、新场景、新对象和不同机器人本体之间的迁移能力，并结合多任务预训练、指令对齐、策略适配和持续学习，分析不同传感器、形态、动作空间和控制接口如何被统一。

## 核心问题

- 机器人模型中的预训练、微调和后训练分别学习什么？
- 新场景、新对象、新任务和长时程泛化如何区分？
- 不同机械臂和人形机器人的动作空间如何对齐？
- 参数高效微调、策略蒸馏和动作映射如何使用？
- 持续学习如何避免灾难性遗忘和能力退化？

## 泛化维度

```text
任务泛化 × 场景泛化 × 对象泛化
× 指令泛化 × 本体泛化 × 时间泛化
```

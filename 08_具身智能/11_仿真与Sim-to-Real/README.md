# 11_仿真与 Sim-to-Real

> 在可控环境中训练和验证策略，并缩小仿真世界与真实世界之间的差距。

## 本章定位

仿真能够降低机器人数据采集和危险探索的成本，但渲染、物理、传感器和控制接口与现实存在差异。本章关注仿真环境、合成数据、域随机化、系统辨识和真机迁移。

## 核心问题

- 物理仿真器、任务环境和数字孪生分别解决什么问题？
- Reality Gap 来自视觉、动力学、传感器还是执行器？
- Domain Randomization 与 Domain Adaptation 如何选择？
- 仿真数据和真机数据应该如何配比？
- 如何判断策略迁移失败的真正原因？

## 迁移链路

```text
仿真任务与资产 → 策略训练 → 域随机化与验证
→ 小规模真机测试 → 误差诊断 → 真机微调与数据回流
```

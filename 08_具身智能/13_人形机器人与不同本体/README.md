# 13_人形机器人与不同本体

> 理解机械臂、移动机器人、四足与人形机器人等不同本体的能力边界，以及人形路线带来的独特系统难题。

## 本章定位

把红杯放进托盘，固定机械臂可以在工作台前完成，轮式移动操作机器人可以跨房间寻找杯子，人形机器人还可能需要跨过门槛、弯腰取杯，再保持平衡完成放置。任务目标相同，身体提供的行动方式和需要满足的约束各有差异。

本章先建立本体与任务的比较框架，再讨论人形机器人的接触、平衡、全身控制和双臂操作。跨本体模型适配见[泛化与跨本体迁移](../11_泛化与跨本体迁移/README.md)，运动规划的共同概念见[导航、操作与任务规划](../04_导航操作与任务规划/README.md)。

## 读完本章，你应该能够

- 根据地形、操作范围和载荷需求比较不同本体。
- 解释人形机器人的接触切换、平衡和操作如何相互影响。
- 描述任务目标如何通过运动规划和全身控制形成关节动作。
- 从数据、能耗、恢复和维护条件判断一个完整任务的可执行程度。

<a id="embodiments"></a>

## 本体能力怎样与任务对应？

| 本体 | 常见任务条件 | 需要关注的限制 |
| --- | --- | --- |
| 固定机械臂 | 固定工位上的抓取、加工和装配 | 安装位置、工作空间、末端工具与负载 |
| 轮式移动机器人 | 连续可通行地面上的运输、巡检和导航 | 门槛、坡度、转弯与停车空间 |
| 轮式移动操作机器人 | 多工位搬运、整理和递送 | 底盘站位、手臂可达、倾覆风险与感知遮挡 |
| 四足机器人 | 台阶、不平地形和需要落脚选择的巡检 | 接触估计、地面摩擦、足端负载和续航 |
| 双足人形机器人 | 面向人类设施的移动、双臂作业与交互 | 平衡、跌倒后果、全身碰撞、能耗与控制复杂度 |

四足增加机械臂后也可以进行操作。轮式平台也可以配备双臂和升降机构。这些类别可以组合，评估时应查看具体的运动机构、传感器和末端工具。

人形的身高、双臂布局和双足支撑提供了适应楼梯、台面和人用工具的可能性，也引入了更多关节协调和动态支撑问题。任务选择可以从完整作业流程开始，确认需要到达哪里、接触什么、携带多重的物体，以及允许投入多少能源和维护时间。移动操作中的底盘和机械臂协同可参考教材中的具体建模方式。[Modern Robotics, Mobile Manipulation](https://modernrobotics.northwestern.edu/nu-gm-book-resource/13-5-mobile-manipulation/)

<a id="balance"></a>

## 平衡为什么会受到手臂动作影响？

固定机械臂的基座受到安装结构约束。双足机器人则通过脚与地面的接触承受重力并改变身体运动，其机身位姿需要结合关节、惯性和接触信息估计。身体质心、线动量、角动量以及可产生的接触力共同影响稳定运动。

### 支撑区域与动态平衡

在水平地面、运动较慢的近似条件下，可用支撑多边形理解质心投影与支撑的关系。动态行走时，还要考虑速度、动量、接触力和未来落脚位置。机器人迈步时会经历双脚支撑、单脚支撑和落脚等阶段，各阶段可用的接触约束不同。

脚底只能在实际接触允许的方向提供力。摩擦不足时可能打滑，力矩或关节能力不足时可能无法保持计划姿态。伸手取杯会改变身体质量分布，提起物体又会增加负载。向柜门施加拉力时，环境的反作用力也会影响平衡。

### 感知与接触估计

IMU、编码器与足底力信息有助于估计身体和接触状态，视觉或深度信息帮助提前选择落脚位置。地面湿滑、柔软或被遮挡时，外观和真实可支撑性可能存在差异。感知式四足运动研究展示了结合外部感知与本体信息来应对复杂地形的方法。[Learning Robust Perceptive Locomotion for Quadrupedal Robots in the Wild](https://arxiv.org/abs/2201.08117)

<a id="whole-body-control"></a>

## 全身控制怎样协调多个目标？

全身控制（Whole-Body Control，WBC）利用多个身体自由度，同时处理末端任务、身体运动和接触约束。常见做法包括逆运动学、逆动力学和约束优化，也可以结合学习得到的运动策略。

```text
任务目标与当前状态
→ 运动、接触和末端目标
→ 全身协调与约束求解
→ 关节目标或力矩
→ 执行反馈与状态更新
```

| 输入或约束 | 取杯任务中的作用 |
| --- | --- |
| 手部目标 | 到达杯体或杯把的可操作区域 |
| 足端与接触计划 | 选择站位，确定何时允许迈步 |
| 躯干与质心目标 | 配合伸手和负载变化调节身体 |
| 关节与驱动约束 | 满足活动范围、速度、力矩和温度限制 |
| 碰撞与环境约束 | 保持手臂、躯干、台面和其他对象之间的可行关系 |

当手部目标与平衡条件冲突时，系统可以调整躯干、改变站位或重新规划接近方式。分层优化可以给目标设定优先级，约束求解还需要处理当前无解的情况。具体实现应明确输出给关节控制器的量，以及状态更新和控制的时序。

高层模型可以指定“取杯”“走到托盘旁”等子目标。运动策略或控制器接收这些目标并持续处理身体状态和接触反馈。评估接口时，要查看目标是否在本体能力范围内、持续时间怎样定义，以及失败如何回传。

<a id="manipulation"></a>

## 双臂与灵巧手增加了哪些协同要求？

双臂搬托盘时，两只手共同约束托盘运动。两侧目标不一致可能产生额外内力，因此需要对齐物体位姿、接触位置和负载分配。单手固定、另一只手拧盖时，还要协调两个动作的时序和受力。

灵巧手可以利用多指接触实现重抓、滚动和手内姿态调整。实际能力取决于手指运动学、驱动力、接触感知、控制和训练覆盖。双指夹爪或吸盘在特定对象上也可形成合适的操作方案，任务设计应结合末端工具确定接触与成功判据。

与人递交杯子时，还需估计对方动作并确认交接状态，例如对方是否已经稳定持有。视觉、力觉与触觉可以提供交接证据，接近速度、释放条件和异常停止由实际系统验证。相关评测见[评测、安全与可靠性](../12_评测安全与可靠性/README.md)。

<a id="learning"></a>

## 人类动作怎样成为机器人技能？

| 数据或方法 | 主要作用 | 需要处理的问题 |
| --- | --- | --- |
| 人类运动捕捉或视频 | 提供动作结构、协调模式和任务示例 | 身体比例、关节、接触与视角差异 |
| 动作重定向 | 将人类动作目标转换到机器人身体 | 可达性、平衡、碰撞和驱动限制 |
| 遥操作 | 收集目标本体上带观测与动作的示范 | 操作延迟、设备映射、保护与重置 |
| 仿真强化学习 | 在重复交互中训练平衡、跟踪和恢复 | 动力学差距、奖励和真实扰动覆盖 |
| 模仿学习 | 用示范训练视觉或状态到动作的策略 | 纠偏状态、多样性和长时程误差 |

HumanPlus 将仿真训练的低层运动跟踪、人类动作跟随采集和视觉模仿学习连接成一套系统，适合观察这些方法如何分工。复用人类数据时，需要同时检查动作重定向和真实本体反馈。[HumanPlus: Humanoid Shadowing and Imitation from Humans](https://arxiv.org/abs/2406.10454)

人形数据采集还涉及跌倒保护、设备复位和操作者投入。完整记录应保留人工接管、支撑装置、任务重置和失败片段。训练时使用了辅助支撑的动作，需要在目标部署条件下重新验证。

<a id="validation"></a>

## 用完整取杯任务验证本体能力

1. **到达工作区域。** 测量通过门槛或狭窄区域的成功率、耗时和干预。
2. **建立操作站位。** 确认目标可见、手部可达，身体和环境满足当前接触条件。
3. **抓取与抬升。** 分别记录抓稳、身体姿态变化、滑动和负载响应。
4. **移动并放置。** 检查携物运动、目标更新、稳定释放和撤离。
5. **持续运行。** 记录能耗、热状态、重复任务表现、停止与恢复时间。

比较本体时可以固定相同作业目标，并分别报告必要的场景改造、人工重置和辅助设施。走得快、抓得稳和长期完成任务分别提供不同阶段的证据，完整任务还要验证阶段交接。

## 自检问题

1. 台面取杯任务中，选择本体前应明确哪些环境与作业条件？
2. 为什么人形机器人抬起物体后可能需要调整身体或站位？
3. 两只手共同持有一个托盘时，控制目标需要怎样关联？
4. 人类演示映射到机器人后，为什么需要重新验证接触和平衡？

<details>
<summary>展开参考答案</summary>

1. 明确位置、地形、通道、对象、操作范围、负载、精度、能耗与人工维护条件。
2. 负载改变质量分布和所需力矩，运动和反作用力也会影响动态平衡。
3. 通过同一个托盘运动和接触约束协调两侧目标，并考虑负载与内力。
4. 人与机器人的身体比例、驱动能力、接触和传感不同，映射后的运动需要满足目标本体约束。

</details>

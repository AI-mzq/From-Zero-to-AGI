# 13_人形机器人与不同本体

> 理解机械臂、移动机器人、四足与人形机器人等不同本体的能力边界，以及人形路线带来的独特系统难题。

## 本章定位

不同机器人本体具有不同的传感器、运动范围、动作空间和任务优势。本章先建立不同本体的比较框架，再重点分析人形机器人如何把双足运动、平衡、全身控制、双臂操作、灵巧手和人机交互结合起来。

## 核心问题

- 人形本体相较机械臂和移动机器人有什么优势与代价？
- 机械臂、移动机器人、四足和人形机器人分别适合哪些任务？
- 行走、平衡和操作为何会相互耦合？
- 高层任务理解如何连接全身运动与低层控制？
- 人形机器人如何采集足够多样且安全的数据？
- 遥操作、仿真、动作重定向和强化学习分别承担什么作用？

## 系统层次

```text
任务理解 → 技能与动作规划 → 全身运动控制
→ 关节执行 → 平衡与接触反馈 → 在线修正
```

# 01_具身智能基础概念

> 建立描述具身智能系统所需的共同语言，理解智能为何必须放在身体、环境和交互中讨论。

## 本章定位

本章从智能体与环境的交互出发，解释本体、观测、状态、动作、策略、奖励、反馈和可供性等基础概念，以及物理世界中的部分可观测性、实时性和不确定性。

## 核心问题

- “具身”给智能系统增加了哪些约束和能力？
- 观测与真实状态有什么区别？
- 本体如何影响可感知的信息和可执行的动作？
- 开环执行与闭环控制为什么会产生不同结果？
- 具身智能的主要任务和学习范式如何划分？

## 核心概念链路

```text
智能体 ↔ 环境
观测 → 状态估计 → 策略 → 动作 → 环境反馈
```

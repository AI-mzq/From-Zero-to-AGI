# 14_人形机器人

> 理解人形本体为何成为通用具身智能的重要载体，以及它带来的独特系统难题。

## 本章定位

人形机器人需要把双足运动、平衡、全身控制、双臂操作、灵巧手和人机交互结合起来。本章关注大模型认知与全身控制如何分层协同，而不将人形机器人等同于具身智能本身。

## 核心问题

- 人形本体相较机械臂和移动机器人有什么优势与代价？
- 行走、平衡和操作为何会相互耦合？
- 高层任务理解如何连接全身运动与低层控制？
- 人形机器人如何采集足够多样且安全的数据？
- 遥操作、仿真、动作重定向和强化学习分别承担什么作用？

## 系统层次

```text
任务理解 → 技能与动作规划 → 全身运动控制
→ 关节执行 → 平衡与接触反馈 → 在线修正
```

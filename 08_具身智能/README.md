# 08_具身智能

> 从多模态理解走向物理世界行动，系统认识机器人如何感知环境、理解任务、生成动作、持续学习并可靠部署。

**By：猫先生 of「魔方AI空间」**

## 🤖 板块定位

具身智能研究的是：智能体如何依托真实或仿真的身体，在环境中通过感知、推理、规划和行动完成任务，并从交互反馈中持续学习。

本板块以大模型为主线，重点解释多模态基础模型如何与机器人系统连接。它不是一套传统机器人学百科，而是帮助读者理解从 VLM、VLN 到 VLA、世界模型和通用机器人策略的完整技术链路。

```text
环境与机器人本体
        ↓
视觉、语言、深度、触觉与本体状态
        ↓
空间表征、任务理解与推理规划
        ↓
动作表示、策略学习与闭环控制
        ↓
数据回流、仿真迁移、评测与真实部署
```

## 🎯 学习目标

完成本板块后，你应该能够：

- 解释具身智能、机器人学习、VLA 和世界模型之间的关系。
- 理解机器人从传感器输入到动作执行的完整闭环。
- 区分导航、操作、移动操作与人形机器人任务。
- 理解模仿学习、强化学习、Diffusion Policy 和通用策略模型的基本路线。
- 分析机器人数据、仿真迁移、跨本体泛化和评测中的核心问题。
- 看懂具身智能论文的系统结构、训练数据、动作表示与实验结论。

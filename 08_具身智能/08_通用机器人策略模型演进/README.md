# 08_通用机器人策略模型演进

> 沿着数据规模、模型结构、动作表示和泛化能力理解通用机器人策略的发展。

## 本章定位

本章不按发布时间堆叠模型，而是分析机器人策略从单任务学习走向多任务、跨场景和跨本体泛化时发生的关键变化，并以 RT 系列、Open X-Embodiment、Octo、π 系列等代表路线作为案例。

## 核心问题

- 机器人基础模型中的“通用”具体指什么？
- 数据规模、多样性和动作空间如何限制模型能力？
- 封闭模型与开放数据、开放权重路线有何差异？
- 哪些进展来自架构变化，哪些主要来自数据和算力？
- 如何公平比较不同本体、任务和评测环境中的结果？

## 分析维度

```text
任务范围 × 数据来源 × 模型架构 × 动作表示
× 跨场景泛化 × 跨本体迁移 × 真实部署表现
```

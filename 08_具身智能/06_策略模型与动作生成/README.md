# 06_策略模型与动作生成

> 研究模型如何表示、预测和生成机器人动作，并在闭环中稳定执行。

## 本章定位

机器人策略把观测和任务条件映射为动作。本章关注动作表示、策略架构和时间建模，连接经典控制、序列模型与 Diffusion、Flow Matching 等生成式方法。

## 核心问题

- 连续控制量、离散动作、关键点、轨迹和动作 Token 如何选择？
- 单步动作与 Action Chunking 有什么取舍？
- Transformer、Diffusion Policy 和 Flow Matching 如何生成动作？
- 观测窗口、动作地平线和执行频率如何影响闭环性能？
- 单任务、多任务和通用策略的能力边界在哪里？

## 策略链路

```text
多模态观测 + 任务条件 → 状态表征
→ 策略模型 → 动作序列 → 控制执行 → 新观测
```

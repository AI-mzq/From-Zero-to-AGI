# 02_机器人系统基础

> 理解大模型进入物理世界前必须面对的机器人本体、传感器、执行器与控制系统。

## 本章定位

本章面向大模型背景读者补充必要的机器人知识，重点建立“感知输入—计算决策—执行控制”的系统认识，不展开为完整的机械、运动学或控制理论教材。

## 核心问题

- 机械臂、移动机器人和人形机器人的本体结构有何差异？
- 相机、深度、触觉、力觉和本体感觉分别提供什么信息？
- 坐标系、位姿、运动学和动力学为什么重要？
- 高层策略如何与低层控制器连接？
- 感知、规划与控制频率如何影响真实系统？

## 系统链路

```text
传感器 → 状态估计 → 任务与运动规划
→ 策略输出 → 控制器 → 执行器 → 物理反馈
```

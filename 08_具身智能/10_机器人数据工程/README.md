# 10_机器人数据工程

> 理解机器人数据从采集、组织、清洗到训练和回流的完整生命周期。

## 本章定位

机器人数据同时包含视觉、语言、本体状态、动作和时间关系，采集成本高且本体差异明显。本章关注数据来源、轨迹结构、质量控制、数据混合和规模化使用。

## 核心问题

- 真机示范、遥操作、仿真、互联网视频和合成数据各有什么价值？
- Episode、轨迹、观测和动作如何对齐？
- 数据格式如何兼容不同任务和机器人本体？
- 如何清洗失败示范、异常动作和时间错位？
- 数据多样性、质量与规模之间如何权衡？
- 训练、部署和错误回流如何形成数据飞轮？

## 数据闭环

```text
任务设计 → 数据采集 → 时间同步与格式化
→ 清洗和质量评估 → 数据混合 → 训练评测 → 失败回流
```

# 08_世界模型与预测控制

> 理解模型如何预测环境变化、想象行动结果，并把预测能力用于机器人决策。

## 本章定位

世界模型学习环境状态及其变化规律；World Action Model 更强调动作与世界演化之间的联系。本章区分视频生成、具身世界模型和动作条件预测，并分析它们与 VLA 的互补关系。

## 核心问题

- 世界模型需要表示什么，又应该预测什么？
- 视频预测与可用于控制的动力学模型有何差异？
- 动作条件预测如何支持规划和策略学习？
- 潜空间规划、想象轨迹和模型预测控制如何工作？
- 世界模型如何评测，视觉逼真是否等于物理正确？

## 基本闭环

```text
当前状态 + 候选动作 → 预测未来状态
→ 评估结果 → 选择动作 → 真实反馈 → 修正模型
```

# 00_板块导读

> 从全局视角认识具身智能的研究对象、系统闭环、主要任务与学习路径。

## 本章定位

具身智能不是单一模型或单项机器人能力，而是感知、认知、规划、动作和反馈共同构成的系统。本章用于建立全局地图，避免把 VLA、世界模型、仿真平台或人形机器人误认为具身智能的全部。

## 核心问题

- 什么是具身智能，它与传统机器人学、Agent 和多模态模型有什么关系？
- 导航、操作、移动操作和人机交互分别解决什么任务？
- 数据、模型、机器人本体和环境如何形成闭环？
- 不同背景的学习者应该从哪条路线进入？

## 知识主线

```text
环境与本体 → 多模态感知 → 世界与任务表征
→ 推理与规划 → 策略与控制 → 行动反馈 → 数据与学习
```

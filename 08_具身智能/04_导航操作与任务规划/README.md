# 04_导航、操作与任务规划

> 理解机器人如何从自然语言目标出发，在空间中移动、操作物体并完成长时程任务。

## 本章定位

本章串联具身智能的三类核心任务：导航解决“去哪里”，操作解决“如何改变物体”，任务规划解决“先做什么、后做什么”。移动操作则要求它们在同一系统中协同。

## 核心问题

- VLN、目标导航、探索和建图有什么区别？
- 抓取、放置、灵巧操作和双臂协作面临哪些约束？
- 高层任务如何分解为技能和低层动作？
- 长时程任务如何维护状态、检测失败并重新规划？
- 语言规划与几何、碰撞和控制约束如何结合？

## 任务层次

```text
自然语言目标 → 任务分解 → 技能选择
→ 运动与操作规划 → 控制执行 → 状态验证与重规划
```

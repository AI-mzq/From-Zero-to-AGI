# 17_实战项目

> 通过可运行、可评测和可复现的实验，把具身智能知识连接成工程闭环。

## 本章定位

实战从仿真和公开数据开始，逐步覆盖数据处理、策略训练、离线评测、仿真执行和系统部署。项目的目标不是展示单次成功视频，而是解释模型为什么成功或失败。

## 实践方向

- 在仿真环境中完成基础导航或操作策略训练。
- 对公开机器人数据集进行读取、清洗、统计和可视化。
- 训练或微调小型行为克隆、Diffusion Policy 或 VLA 模型。
- 建立固定任务集，比较不同模型、输入和动作表示。
- 记录失败轨迹，分析感知、规划、策略与控制误差。
- 完成模型服务、控制接口、日志回放和安全停止闭环。

## 项目闭环

```text
明确任务 → 准备环境与数据 → 建立基线
→ 训练策略 → 离线评测 → 仿真或真机执行
→ 失败分析 → 回归验证 → 可复现交付
```

## 复现要素

每个项目应明确环境依赖、数据版本、运行入口、预期结果、评测方法、资源需求和已知限制。

# 05_机器人学习基础

> 从示范、奖励和历史交互中学习策略，并用闭环执行检验学到的行为。

## 本章定位

第 04 章把“将红色杯子放入托盘”拆成导航、抓取、搬运和放置。本章把镜头拉近到抓取技能。杯子偏离常见位置时，机器人该怎样调整夹爪？第一次没夹住时，它有哪些机会学会重新对准？

判断一种学习方法是否适用，可以先问三个问题：**训练时有什么反馈，能否继续采集交互，新数据能覆盖哪些失败状态？** 本章用同一个抓杯任务比较训练方法。动作表示和模型架构见[策略模型与动作生成](../06_策略模型与动作生成/README.md)。

## 读完本章，你应该能够

- 从一个机器人技能中找出策略输入、动作、训练信号和任务成功条件。
- 根据示范质量、奖励可靠性和交互成本选择训练方法。
- 解释为什么离线预测准确的策略可能在闭环执行时反复失败。
- 设计能区分任务完成、恢复能力和跨场景泛化的评测。

<a id="policy"></a>

## 策略学到的是什么？

策略根据当前观测、必要的历史和任务目标选择动作。抓杯时，输入可以是相机画面、关节状态和目标杯子，输出可以是末端位姿增量与夹爪指令。控制器执行指令后，杯子可能移动、被遮挡或滑落。新的观测进入策略，影响下一次决策。

```text
目标 + 当前观测与历史 → 策略 → 动作 → 环境变化 → 新观测
                         ↑                        │
                         └────────────────────────┘
```

一次执行会留下按时间排列的**轨迹**。示范轨迹可以提供观测和专家动作，强化学习轨迹通常还需要奖励、下一观测及终止信息。真实状态往往只能部分观测。例如同一帧画面可能对应“已经夹稳”和“杯子正在滑动”，短时历史或触觉反馈可以帮助策略区分这两种情况。

<a id="imitation"></a>

## 从示范学习行为

### 行为克隆与误差累积

行为克隆（Behavior Cloning，BC）将示范中的动作作为监督标签。给定专家当时看到的画面和机器人状态，训练策略预测专家做出的动作。只要示范可靠、任务边界明确，BC 就能作为便于比较的基线。

假设示范里夹爪每次都从杯子正前方接近。上线后，策略第一次横向偏了一点，下一帧就可能出现训练时很少见的相对位置。模型随后继续按熟悉的动作靠近，偏差可能进一步扩大。这是由**策略自身动作引起的分布偏移**。在专家轨迹上测得的单步误差，只能说明模型对那批观测的拟合程度。

DAgger 的做法是让学习策略参与产生轨迹，请专家为这类观测标注应采取的动作，再把新样本并入训练集。在机器人实践中，可在仿真或受控条件下收集纠正示范。仅有人类接管的起止记录时，还要确认是否保留了可用于训练的观测和纠正动作。[Ross 等人的 DAgger 论文](https://proceedings.mlr.press/v15/ross11a.html)

### 逆强化学习从示范推断什么？

逆强化学习（Inverse Reinforcement Learning，IRL）尝试找出能够解释示范行为的奖励函数，再据此求策略。比如专家搬运杯子时总保持直立，系统可以把这类行为视为推断偏好的证据。多种奖励函数可能解释同一批示范，需要用额外假设或新场景检验推断结果。行为克隆直接拟合动作，逆强化学习则以示范为证据推断行为背后的目标。

<a id="reinforcement"></a>

## 从奖励学习行为

强化学习（Reinforcement Learning，RL）优化一段交互中的累计奖励，也称**回报**，通常会对未来奖励做折扣。抓杯任务中的成功信号可能直到杯子放稳才出现，算法需要判断之前的接近、夹持和搬运分别对结果有多大贡献，这就是**信用分配**问题。

- **稀疏奖励**只在达到明确条件时给出反馈。成功很少发生时，策略难以通过探索获得足够的成功轨迹。
- **稠密奖励**为接近杯子、完成夹持等中间进度提供反馈。若只奖励末端与杯子的距离，策略可能长时间贴近杯子，即使从未完成搬运。
- **安全约束**由执行系统落实，例如工作空间限制、碰撞监测和异常停止。奖励可以引导偏好，执行限制需要在动作发出和执行时生效。

### 在线、离线与混合训练

| 方式 | 训练期间怎样获得数据 | 抓杯场景中的主要约束 |
| --- | --- | --- |
| 在线 RL | 持续从环境采集新交互并更新策略，可以复用旧经验 | 能收集当前策略遇到的状态，真机时间、磨损和探索风险需要管理 |
| 离线 RL | 用固定的历史交互数据优化回报 | 需要动作、后继观测和可用奖励等信息，数据很少覆盖的动作难以可靠估值 |
| 离线预训练再在线微调 | 先用已有数据初始化，再收集受控的新经验 | 可以补齐部署条件中的缺口，新旧数据的动作定义和奖励口径需对齐 |

同一批固定轨迹可以用于行为克隆，也可以在有可用奖励时用于离线 RL。前者用动作作监督，后者用奖励优化回报。带奖励的历史轨迹可以来自专家、旧策略或多种策略的混合。若历史记录只覆盖正面夹持，模型对侧向夹持的高价值估计就缺少直接证据。典型方法如 IQL 在训练中避免直接查询数据集外动作的 Q 值，仍需要检查数据覆盖及真实执行表现。[Offline Reinforcement Learning with Implicit Q-Learning](https://arxiv.org/abs/2110.06169)

<a id="representation"></a>

## 从无动作标注的数据学习表征

自监督学习可以从原始数据构造训练信号，例如遮住图像的一部分再重建，或利用同一段视频的时间关系学习表征。表征预训练希望编码器保留下游需要的信息，例如杯口方向和前后帧中的物体变化。R3M 将视频中的时间关系与语言对齐结合，学习可供下游操作策略使用的视觉表征。[R3M: A Universal Visual Representation for Robot Manipulation](https://arxiv.org/abs/2203.12601)

只有视频时，可以学习物体外观和动作进展。夹爪应该沿哪个坐标轴移动、施力多少，还需要与具体机器人对应的动作监督、交互反馈或控制接口。可以将预训练编码器接入策略，再用示范训练动作输出，并比较冻结编码器和微调编码器在同一评测集上的结果。

<a id="workflow"></a>

## 用抓杯任务选择训练路线

同一个任务可以组合多种方法。训练顺序取决于已经掌握的数据和执行失败的位置。

| 手头的条件或执行证据 | 可采用的训练路线 | 要验证的结果 |
| --- | --- | --- |
| 有一批动作对齐、覆盖常见杯子位置的遥操作示范 | 用 BC 建立基线 | 从新初始位置能否抓起并放稳 |
| 夹爪稍偏后经常反复空抓 | 补容易偏离的起点及纠正示范，再训练 | 失败后能否回到可继续执行的状态 |
| 已有多批成功和失败的历史交互，且能按同一标准判定结果 | 比较离线 RL 与 BC，检查历史数据是否覆盖候选行为 | 收益能否在闭环中复现 |
| 可以在仿真中反复交互，并可靠检测放置成功 | 通过在线 RL 练习，并在受控条件下验证迁移 | 仿真中的改进能否在不同摩擦、遮挡和接触条件下保留 |
| 只有大量视频和少量带动作示范 | 用视频预训练表征，再用少量机器人示范训练策略 | 同等示范预算下是否提升泛化 |

采集与组织数据的工程细节见[机器人数据工程](../09_机器人数据工程/README.md)，仿真到真机的验证见[仿真与 Sim-to-Real](../10_仿真与Sim-to-Real/README.md)。

<a id="evaluation"></a>

## 用闭环评测定位失败

1. **定义成功条件。** 对抓杯和放置分别记录结果。杯子被抬起、搬运时保持稳定、释放后留在托盘内，是三个可以分别观察的结果。
2. **按轨迹和场景划分数据。** 相邻帧放进不同集合容易高估泛化表现。按问题保留未见过的对象、背景或初始位姿。
3. **执行完整任务。** 使用一致的起始条件、超时和重试预算，记录成功率、完成时间、恢复成功率及人工接管。给出评测次数，便于判断波动。
4. **回放失败前后的观测与动作。** 如果识别错了杯子，先检查视觉输入与对象覆盖。如果杯子已经对准却滑落，再检查夹持反馈、动作时序和接触条件。用相同评测条件验证下一轮改动。

## 自检问题

1. 为什么行为克隆在验证集上的动作误差很低，真机仍可能反复空抓？
2. 同一批历史数据分别用于行为克隆与离线 RL 时，需要哪些不同的监督信息？
3. 如果只奖励夹爪靠近杯子的距离，策略可能学到什么行为？你会怎样验证任务是否完成？
4. 预训练编码器能辨认杯子后，训练抓取策略还需要什么？

<details>
<summary>展开参考答案</summary>

1. 策略的动作改变下一时刻的观测。专家验证集可能缺少发生偏移时的画面及纠正动作，后续小误差会累积。
2. 行为克隆依赖观测与目标动作的对应关系。离线 RL 使用历史状态转移与奖励来优化回报，还需要关注罕见动作和状态的数据覆盖。
3. 策略可能只学会靠近或停在杯子附近。可以分别验证夹持、抬升和稳定放置，并检查该行为是否增加了完整任务成功率。
4. 需要与实际本体匹配的动作或交互信号，以及闭环验证。具体需要哪些信息取决于动作表示、控制接口和训练方法。

# 05_机器人学习基础

> 理解机器人如何从示范、奖励、交互和无标注数据中学习行为。

## 本章定位

本章建立策略学习的基础框架，比较模仿学习、行为克隆、强化学习、离线强化学习和自监督学习，并解释分布偏移、误差累积、探索和奖励设计等共性难题。

## 核心问题

- 示范数据如何转化为可执行策略？
- 行为克隆为什么容易在闭环执行中累积误差？
- 在线与离线强化学习分别适合哪些机器人场景？
- 奖励、探索和安全约束为什么难以设计？
- 预训练表征如何提高数据效率和泛化能力？

## 学习范式

```text
人类示范 → 模仿学习
环境奖励 → 强化学习
历史轨迹 → 离线学习
无标注交互 → 自监督预训练
```

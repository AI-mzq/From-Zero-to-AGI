# 03_具身感知与空间智能

> 从“看见物体”走向“理解可行动的三维空间”。

## 本章定位

具身感知不仅要识别图像内容，还要估计位置、几何、运动、接触关系和可执行动作。本章连接计算机视觉、多模态理解与机器人空间表征。

## 核心问题

- RGB、深度、点云、触觉和本体状态如何融合？
- 目标检测、分割、跟踪和姿态估计如何服务行动？
- 2D、3D、4D、占据表示和场景图各自适合什么任务？
- 什么是可供性，它如何连接物体认知与动作？
- 机器人如何形成空间记忆并处理遮挡与动态环境？

## 感知层次

```text
传感器信号 → 对象与几何 → 空间关系与场景
→ 可供性与交互可能 → 面向任务的状态表示
```

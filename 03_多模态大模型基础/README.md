# 03_多模态大模型基础

> 多模态大模型基础是面向 MLLM、VLM、图文生成、视频理解、语音交互和多模态 Agent 的长期知识库，系统连接基础概念、模型架构、数据训练、评测和实战。

**By：猫先生 of 「魔方AI空间」**

## 板块定位

多模态大模型不是简单地“给 LLM 加一张图”，而是让模型能够在文本、图像、视频、音频、3D、传感器等不同模态之间建立对齐、理解、生成和行动能力。

本板块关注四条主线：

- **理解主线**：图像、视频、音频如何被编码成模型可处理的表示。
- **对齐主线**：不同模态如何通过投影层、Cross-Attention、Q-Former、Token 化等方式接入 LLM。
- **生成主线**：文本、图像、视频、音频之间如何互相生成与控制。
- **应用主线**：多模态问答、文档理解、视频理解、语音助手、GUI Agent、RAG 和工具调用如何落地。
